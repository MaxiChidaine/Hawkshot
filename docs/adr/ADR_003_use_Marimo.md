# ADR-003 | Use Marimo 

## Status 

Proposed 

## Context 

The project requiers an interactive environment for exploratory data analysis (EDA).

Sereral options are available :

- Jupyter Notebook
- JupyterLab
- VS Code Notebooks
- Marimo 

## Decision

Evaluate Marimo as the notebook environment.

## Rationale

Marimo provides : 
- Python-based notrebooks.
- Better git integration. 
- Reactive execution model.
- Cleaner version control.

The final adoption will be confirmed after practical evaluation.
