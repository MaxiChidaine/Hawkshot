# Hawkshot

Hawkshot is a machine learning project focused on predictive maintenance for turbofan engines based on the dataset NASA-CMAPSS.

## Objectives

- Simulation of an electric motor
- Data storage in PostgreSQL
- Data preprocessing
- Anomaly detection
- FastAPI
- Streamlit dashboard

## Technologies

- Python
- PostgreSQL
- SQLAlchemy
- scikit-learn
- FastAPI
- Streamlit
- Docker
- uv
- marimo
